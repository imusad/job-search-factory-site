Privacy Policy

Last updated: 25 November 2026

Job Search Factory ("the app") is a personal tool used by a single person, its owner. This policy explains how the app handles Google user data.

Data the app accesses

  • Google Sheets: to create and update the owner's job tracker spreadsheet.
  • Google Drive (drive.file scope): only files and folders the app itself creates, to store application documents.
  • Google Docs and Google Slides: to create documents and presentations inside those folders.
  • Gmail (gmail.send scope): only to send summary and confirmation emails to the owner. The app cannot read, search or delete email.

How the data is used

Google user data is used only to provide these features to the owner. It is not sold, shared with third parties, or used for advertising. It is not used to train general-purpose AI models.

Storage and security

Documents and the tracker live in the owner's own Google account. The app's access token is stored as an encrypted secret in the owner's private source-code repository and its automation environment. No other database holds Google user data.

Retention and deletion

The owner can delete any file at any time in Google Drive. Access can be revoked at any time at myaccount.google.com/permissions, after which the app can no longer access the account.

Limited Use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be raised as an issue on this site's GitHub repository.
